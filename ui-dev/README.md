# ui-dev

UI development toolkit for Claude Code.

## Purpose

Provides tools and workflows for UI development tasks, including browser automation for troubleshooting and validating UI changes.

## Features

### Skills

- **agent-browser** - Headless browser automation via the `agent-browser` CLI. Use for troubleshooting UI issues or validating UI changes with commands for navigation, clicking, typing, and capturing snapshots.
- **frontend-design** - Create distinctive, production-grade frontend interfaces with high design quality. Generates creative, polished code that avoids generic AI aesthetics.
